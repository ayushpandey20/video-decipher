# Video Decipher

A lightweight web application that takes YouTube video URLs and generates instant structured summaries and analytical breakdowns, with support for PDF export.

## Features

- **Instant Video Summaries**: Input any YouTube link to generate key takeaways and breakdown.
- **One-Click PDF Export**: Clean formatted PDF generation using `html2pdf.js`.
- **Cosmic Dark UI**: Glassmorphism dashboard layout built with HTML5, CSS3, and modern JavaScript.
- **Spring Boot Backend**: REST API handling requests and background integrations.

## Tech Stack

- **Backend**: Java 17+, Spring Boot
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Build Tool**: Maven
- **PDF Generation**: `html2pdf.js`
